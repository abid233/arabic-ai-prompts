# البحث والتحليل

## 1. تحليل موقع وتحويله إلى خطة تطوير

```text
حلل هذا الموقع: [الرابط].

الهدف من الموقع: [بيع/جمع عملاء محتملين/تعريف/حجز]. الجمهور: [الجمهور].

أنشئ تقريرًا مختصرًا وعمليًا يتضمن: وضوح الرسالة، تجربة الجوال، الثقة، الدعوات للإجراء، المحتوى، السرعة المتوقعة، SEO الأساسي، وفرص التحويل.
رتّب التوصيات إلى: تأثير عالٍ/تنفيذ سريع، تأثير عالٍ/تنفيذ متوسط، وتحسينات لاحقة. اكتب لكل توصية سببها، طريقة تنفيذها، ومؤشر النجاح.
إذا لم تستطع فتح الرابط، اطلب لقطات شاشة أو نص الصفحة بدل اختلاق تحليل.
```

## 2. تلخيص تقرير طويل إلى قرارات

```text
اقرأ التقرير المرفق وحوّله إلى ملخص تنفيذي عربي.

أريد: أهم 5 نتائج، المخاطر أو العوائق، القرارات المطلوبة، خطة عمل من 30 يومًا، والجهات أو الأدوار المسؤولة. لا تكرر محتوى التقرير، واذكر أرقامًا فقط إذا كانت موجودة فيه.
```

## 3. مقارنة خيارات قبل اتخاذ قرار

```text
قارن بين الخيارات التالية لاتخاذ قرار بشأن [الموضوع]:
1) [الخيار الأول]
2) [الخيار الثاني]
3) [الخيار الثالث]

المعايير الأهم: [التكلفة، الوقت، سهولة الاستخدام، الخصوصية، التوسع...].
أنشئ جدول مقارنة واضحًا، ثم قدّم توصية مشروطة: متى أختار كل خيار؟ وما المخاطر التي يجب أن أتأكد منها قبل التنفيذ؟
```
