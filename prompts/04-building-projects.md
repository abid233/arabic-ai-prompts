# البرمجة وبناء المشاريع

## 1. تحويل فكرة إلى مواصفات منتج

```text
أريد بناء [موقع/تطبيق/أداة] باسم [الاسم].

المشكلة التي يحلها: [المشكلة]. المستخدمون: [المستخدمون]. النتيجة التي يريدونها: [النتيجة].

حوّل الفكرة إلى مواصفات MVP تشمل: قصص المستخدمين، الصفحات أو الشاشات، البيانات المطلوبة، الصلاحيات، الحالات الاستثنائية، ومؤشرات النجاح.
اقترح ما يجب أن يدخل في النسخة الأولى وما يؤجل. لا تبدأ بكتابة كود قبل عرض خطة تنفيذ مختصرة.
```

## 2. مراجعة كود آمنة

```text
راجع الكود التالي كمراجع هندسي:
[الصق الكود]

افحص: الأخطاء المنطقية، الأمن، التعامل مع البيانات الحساسة، الأداء، سهولة الصيانة، وتجربة الخطأ للمستخدم. أعطني النتائج مرتبة حسب الخطورة، مع شرح مختصر واقتراح إصلاح محدد لكل نقطة.
لا تقترح نشر مفاتيح أو تجاوز صلاحيات أو تعطيل أي حماية أمنية.
```

## 3. طلب بناء صفحة عربية RTL

```text
ابنِ صفحة ويب عربية RTL لـ[اسم المنتج].

الجمهور: [الجمهور]. الهدف: [الهدف]. الأقسام المطلوبة: [الأقسام].
اجعل التصميم متجاوبًا للجوال، واضحًا، سهل الوصول، وباللغة العربية. استخدم بيانات تجريبية فقط ولا تضع مفاتيح API أو أسرارًا داخل الواجهة.

قبل الكود: اكتب هيكل الصفحة وخطة الملفات. بعد ذلك قدّم التنفيذ مع تعليمات تشغيل مختصرة.
```
