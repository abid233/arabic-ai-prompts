# العمل والإنتاجية

## 1. خطاب أو رسالة رسمية

```text
اكتب خطابًا عربيًا رسميًا من [الجهة/الاسم] إلى [الجهة المستلمة] بشأن [الموضوع].

المعلومات التي يجب تضمينها: [النقاط].
النبرة المطلوبة: [رسمية جدًا/رسمية ودودة].
النتيجة المطلوبة من المستلم: [موافقة/تزويد معلومات/تحديد موعد].

اجعل الخطاب واضحًا ومباشرًا، مع عنوان مناسب، مقدمة قصيرة، طلب محدد، وخاتمة مهنية. لا تضف ادعاءات أو بيانات غير مزودة.
```

## 2. تحويل اجتماع إلى خطة تنفيذ

```text
هذه ملاحظات اجتماع:
[الصق الملاحظات]

حوّلها إلى محضر اجتماع منظم يشمل: القرارات، المهام، المسؤول عن كل مهمة، الموعد المتوقع، الأسئلة المفتوحة، والمخاطر. إذا لم يظهر مسؤول أو موعد، ضع "غير محدد" ولا تخمّن.
```

## 3. بناء إجراء تشغيلي SOP

```text
اكتب إجراءً تشغيليًا قياسيًا لعملية: [اسم العملية].

الهدف: [الهدف]. الأشخاص المشاركون: [الأدوار]. الأدوات: [الأدوات].

اكتب: نطاق الإجراء، المتطلبات، الخطوات مرقمة، نقاط التحقق من الجودة، الاستثناءات، وما الذي يجب توثيقه. اجعله بسيطًا بحيث يستطيع موظف جديد تطبيقه.
```
