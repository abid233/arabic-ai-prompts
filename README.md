# مطالبات عربية مفيدة للذكاء الاصطناعي

مكتبة عربية عملية من المطالبات الجاهزة للاستخدام مع **ChatGPT** و**Claude**. صُممت لتساعدك على الوصول إلى نتيجة مرتبة وقابلة للتنفيذ، لا مجرد إجابة عامة.

## كيف تستخدم المكتبة؟

1. اختر القسم المناسب من مجلد `prompts`.
2. انسخ المطالبة كاملة.
3. استبدل النص بين الأقواس المربعة مثل `[اسم المشروع]` و`[الجمهور]`.
4. أرفق الملفات أو الروابط ذات الصلة عند الحاجة.
5. اطلب من النموذج أن يسألك سؤالًا مجمعًا واحدًا فقط عند نقص المعلومات المؤثرة.
